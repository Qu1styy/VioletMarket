# Violet Market

Клиентское SPA-приложение интернет-магазина на Vue 3. Violet Market отображает каталог товаров, позволяет зарегистрироваться и войти в аккаунт, добавлять товары в корзину, изменять их количество, оформлять заказы и просматривать историю покупок.

## Возможности

- просмотр каталога товаров;
- регистрация и авторизация пользователей;
- выход из аккаунта;
- сохранение токена авторизации в `localStorage`;
- добавление товаров в корзину;
- изменение количества товаров и удаление позиций из корзины;
- оформление заказа;
- просмотр истории заказов;
- защита маршрутов для авторизованных и неавторизованных пользователей;
- адаптивный интерфейс для мобильных устройств.

## Стек

- [Vue 3](https://vuejs.org/);
- [Vue Router 4](https://router.vuejs.org/);
- [Vuex 4](https://vuex.vuejs.org/);
- Vue CLI 5;
- JavaScript и Fetch API;
- CSS без стороннего UI-фреймворка.

## Структура проекта

```text
public/
  index.html              HTML-шаблон приложения

  App.vue                 Корневой компонент и навигация Violet Market
```

## Маршруты

| Путь | Назначение | Доступ |
| --- | --- | --- |
| `/` | Каталог товаров | Все пользователи |
| `/login` | Вход в аккаунт | Только неавторизованные |
| `/register` | Регистрация | Только неавторизованные |
| `/cart` | Корзина | Только авторизованные |
| `/orders` | История заказов | Только авторизованные |
| `/logout` | Выход из аккаунта | Только авторизованные |

## Требования

- Node.js и npm;
- доступ к backend API;
- включённый JavaScript в браузере.

## Установка и запуск

```bash
git clone https://github.com/Qu1styy/Vue4.git
cd Vue4
npm install
npm run serve
```

После запуска приложение обычно доступно по адресу `http://localhost:8080`.

## Настройка API

Перед запуском проверьте файл `.env`:

```dotenv
VUE_APP_API=http://lifestealer86.ru/api-shop
```

Переменная `VUE_APP_API` используется в `src/utils/api.js` для запросов авторизации, каталога, корзины и заказов. После изменения `.env` перезапустите dev-сервер.

## Сборка для production

```bash
npm run build
```

Готовые файлы будут помещены в директорию `dist/`.

## API-эндпоинты

- `POST /login` — вход;
- `POST /signup` — регистрация;
- `GET /logout` — выход;
- `GET /products` — получение каталога;
- `POST /cart/:productId` — добавление товара в корзину;
- `GET /cart` — получение корзины;
- `DELETE /cart/:id` — удаление позиции из корзины;
- `POST /order` — оформление заказа;
- `GET /order` — получение заказов.

Для защищённых запросов токен передаётся в заголовке `Authorization: Bearer <token>`. Токен хранится в `localStorage` под ключом `myAppToken`.
