# Wildberrrris

Клиентское SPA-приложение интернет-магазина на Vue 3. Приложение отображает каталог товаров, позволяет зарегистрироваться и войти в аккаунт, добавлять товары в корзину, изменять количество товаров, оформлять заказы и просматривать историю заказов.

## Возможности

- просмотр каталога товаров;
- регистрация нового пользователя;
- авторизация и выход из аккаунта;
- сохранение токена авторизации в `localStorage`;
- добавление товаров в корзину;
- изменение количества товаров и удаление позиций из корзины;
- оформление заказа;
- просмотр ранее оформленных заказов;
- защита маршрутов для авторизованных и неавторизованных пользователей;
- адаптивный интерфейс для мобильных устройств.

## Стек

## Маршруты

| Путь | Назначение | Доступ |
| --- | --- | --- |
| `/` | Каталог товаров | Все пользователи |
| `/login` | Вход в аккаунт | Только неавторизованные |
| `/register` | Регистрация | Только неавторизованные |
| `/cart` | Корзина | Только авторизованные |
| `/orders` | История заказов | Только авторизованные |
| `/logout` | Выход из аккаунта | Только авторизованные |

## Установка и запуск

1. Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/Qu1styy/Vue4.git
cd Vue4
```

2. Установите зависимости:

```bash
npm install
```

3. Проверьте адрес backend API в `.env`:

```dotenv
VUE_APP_API=http://lifestealer86.ru/api-shop
```

Переменная `VUE_APP_API` используется в `src/utils/api.js` для запросов авторизации, каталога, корзины и заказов. После изменения `.env` перезапустите dev-сервер.

4. Запустите приложение в режиме разработки:

```bash
npm run serve
```

После запуска Vue CLI выведет локальный адрес приложения в терминал, обычно `http://localhost:8080`.

## Сборка для production

```bash
npm run build
```

Готовые файлы будут помещены в директорию `dist/`.

## Взаимодействие с API

Клиент обращается к backend через `src/utils/api.js`. Используемые endpoint'ы:

- `POST /login` — вход;
- `POST /signup` — регистрация;
- `GET /logout` — выход;
- `GET /products` — получение каталога;
- `POST /cart/:productId` — добавление товара в корзину;
- `GET /cart` — получение корзины;
- `DELETE /cart/:id` — удаление позиции из корзины;
- `POST /order` — оформление заказа;
- `GET /order` — получение заказов.

Для защищённых запросов токен передаётся в заголовке `Authorization: Bearer <token>`. Токен сохраняется в `localStorage` под ключом `myAppToken`.

## Архитектура состояния

Vuex хранит:

- `token` — токен текущего пользователя;
- `products` — список товаров;
- `cart` — содержимое корзины;
- `orders` — история заказов.

Компоненты вызывают actions хранилища, а actions используют функции API из `src/utils/api.js`. Маршрутизатор проверяет getter `isAuthenticated` перед переходом на защищённые страницы.
